# Solace Full Audit + Fix Report — 2026-07-25

Branch: `integrate/atlas-pipeline` (feature/copilot-phi-isolation ⨯ main, merged)

## Scope

Five parallel auditors swept the codebase: backend security/compliance (vs
`CONSTITUTION.md`), backend correctness, frontend app, landing + demo, and
infra/deps/secrets. Findings were re-verified against this branch (the auditors
first scanned `main`), then confirmed bugs were fixed and the full test + build
suite re-run.

## Headline result

- Backend: **743 passed, 6 skipped** before and after the fixes — no regressions.
- Frontend + landing: clean `tsc` + `vite build`.
- Secret scan: **clean** — no credentials, keys, or tracked `.env` with secrets.

## Already resolved on this branch (were open on `main`)

The PHI-isolation branch already fixes what the security auditor flagged on `main`:

- **Cross-tenant PHI disclosure in EHR Copilot** — `services/copilot/context.py`
  `build_chart` now calls `tenant.assert_patient_in_hospital(...)` at the PHI
  boundary, so every copilot entry point (ask/summary/scan/autopopulate) rejects
  a cross-hospital `patient_id` with a uniform 404.
- **Unauthenticated governance override-log leak** — `routers/governance.py` now
  redacts `patient_id`/`clinician_id`/`notes` on the public log and splits the raw
  log behind a clinician-authed `/override-log/full`.
- **SEC-004 consent gate on clinician-side AI** — `build_chart` now enforces
  `consent.assert_ai_consent(patient)` before any model call.

## Fixes applied this pass

| ID | Sev | File | Fix |
|----|-----|------|-----|
| A | HIGH | `backend/db/storage.py` `_ddb_update_patient` | `_to_ddb` dropped `None`, so AWS-mode updates could never clear a field (pain-flag re-arm kept stale `acknowledged_*`, diverging from local mode). Now splits into `SET` (non-None) + `REMOVE` (None) clauses; guards empty updates. |
| B | HIGH | `requirements-lambda.txt` | numpy pinned `1.26.4` in Lambda vs `2.1.2` in training; a numpy-2 pickle can fail to load under numpy 1 at cold start, silently disabling the ML ensemble. Bumped Lambda to `2.1.2` (DEPS-004). **Needs a Lambda image rebuild + deploy to fully verify.** |
| C | MED | `backend/lib/jwt_auth.py` `record_failed_attempt` | Sliding-window reset was a no-op `pass`; the failed-login counter was monotonic, so stray failures over days could trigger a false lockout. Now reads prior `last_failed_at` and starts a fresh count when the window has expired. |
| D | LOW | `backend/db/storage.py` list sort | `int(p.get("esi_level", 5))` raised on a present-but-None value (500 on `/patients` + `/admin`). Now `int(p.get("esi_level") or 5)`. |
| E | LOW | `backend/services/voice_agent/session.py` `hash_phone` | Unsalted SHA-256 over the ~10^10 US phone space is reversible. Now HMAC-SHA256 with the CMK-encrypted auth secret (same salt `services/sms.py` uses), with an unsalted fallback only in local dev. |
| F | LOW | `backend/routers/voice.py` | Simulator turn logged the whole `tool_result` as `tool_input`; now matches the Twilio path (`.get("input", {})`). |
| G | HIGH | `frontend/src/pages/PatientResult.tsx` | The result screen only hydrated from `sessionStorage`, so a refresh / restored mobile tab / another device showed the "Preparing your assessment" spinner forever. Now rebuilds the assessment from the public patient endpoint (`buildResultFromPublic`) when the seed is gone. |
| H | MED | `frontend/src/pages/VoiceAgent.tsx` | TTS `<audio>` was never stopped on unmount, bleeding over the next screen. Added an unmount cleanup that pauses + tears it down, and a pause before reassigning `src`. |
| I | MED | `frontend/src/pages/PatientResult.tsx` | `careRec` stale closure in the 15s poll overwrote the hydrated value; now a functional updater (`prev => prev ?? ...`). |
| J | LOW/MED | `landing/`, `demo/` | Deleted 10 unreferenced files (~575 lines); added a catch-all 404 route; removed all em/en dashes from user-facing copy (per the no-dash rule). |

## Landing → app funnel wired

The marketing site had no path into the app. Added `landing/src/lib/appUrl.ts`
(`VITE_APP_URL`, default `solaceaidemo.vercel.app`) and pointed the nav CTA
(desktop + mobile) and the Pricing "Start free" tier at `/get-started`, with
"Book a Demo" → `/demo` and "Talk to us" → `/contact`. Full pipeline now flows:
**landing → /get-started → hospital provisioning (unique slug + magic-link login)
→ onboarding wizard → workspace with Atlas copilot.**

## Not fixed (deliberate — flagged for follow-up)

- **B needs a Lambda rebuild+deploy** to confirm the re-pickled models load under
  numpy 2.1.2. LightGBM per-fold `.txt` models are version-agnostic; only the
  `.pkl` sklearn path is at risk.
- **Widespread `any` outside catch blocks** (QUAL-007) across clinician pages and
  `lib/api.ts` Wave 1-4 wrappers — needs typed request/response interfaces, a
  larger typing pass than this audit.
- **Hardcoded English on some patient screens** (USAB-008) — ESI meaning, wait,
  and SMS strings render literal English regardless of language; route through
  `t()` + add i18n keys.
- **No global 401 response interceptor** — only `ClinicianDashboard` reacts to an
  expired token; other clinician pages surface a raw error.
- **Infra hygiene (low):** AWS account ID hardcoded in `buildspec.yml`/scripts
  (public repo); `docker build` missing `--platform=linux/arm64`.
- **CCPA delete/export** (COMP-010) still unwired; **provenance override log** is
  now DDB-backed on this branch but confirm the S3 6-year archive path.
